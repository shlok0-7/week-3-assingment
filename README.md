# ShloK Responsive Portfolio

A responsive personal portfolio built with semantic HTML5 and external CSS.

## Files
- `index.html` — semantic page structure
- `style.css` — external responsive styling
- `assets/profile.svg` — local profile asset

## GitHub Pages
1. Create a public repository.
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. GitHub Pages will publish the site at the repository's Pages URL.

Replace the placeholder repository links in `index.html` with the URLs of your actual project repositories.
